WATDEPEK Marketplace – Website Description
WATDEPEK Marketplace is a web‑based application designed to simulate the core functions of a modern e‑commerce platform. Built with HTML, CSS, and JavaScript, it provides both buyers and sellers with an interactive environment for managing products, shopping, and personal profiles.

🔑 Key Features of WATDEPEK Marketplace
👤 User Authentication  
Secure login and registration system using localStorage to store user credentials.

📦 Product Management  
Sellers can upload products with name, price, category, and image. Products are displayed dynamically in a responsive grid layout.

🔍 Search & Category Filtering  
Buyers can search products by name or filter by category (e.g., Grocery, Electronics, Hygiene).

🛒 Shopping Cart  
Items can be added to a cart, viewed in a fixed sidebar, and checked out with automatic total price calculation.

🏠 Profile Management  
Users can save personal details (name, address, contact number) which are integrated into the checkout process.

🛠️ Seller Panel  
A dedicated panel allows sellers to manage product uploads and preview images before publishing.

⭐ Ratings System  
Products include a rating feature, enabling buyers to interact and provide feedback.

🎨 Design & Layout
•Responsive Grid Layout for product display.
•Sidebar Navigation for quick category access.
•Header Controls for profile, cart, seller mode, and logout.
•Clean UI Styling with warm color tones for a professional yet approachable look.

🎯 Purpose
The WATDEPEK Marketplace project demonstrates the fundamental structure of an e‑commerce website, including:
1. User authentication
2. Product catalog management
3. Cart and checkout flow
4. Profile integration
5. Seller functionality

⚙️ Technologies Used
•HTML – Structure and layout of the marketplace.
•CSS – Styling, colors, and responsive design.
•JavaScript – Handles login, product upload, cart management, search, filtering, and profile saving.
•LocalStorage – Stores user accounts, products, cart items, and profile data.
